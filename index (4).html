ความรู้เบื้องต้นเกี่ยวกับ OCI

Oracle Cloud Infrastructure (OCI) คือแพลตฟอร์มคลาวด์ของ Oracle ที่เติบโตมาจากความเชี่ยวชาญด้านฐานข้อมูลองค์กร ออกแบบเป็นคลาวด์รุ่นที่สอง รองรับงานประสิทธิภาพสูง (HPC) และงาน AI

เครือข่ายความหน่วงต่ำ

โครงสร้างเครือข่ายแบบ Flat Network แบนด์วิดท์สูง รองรับฐานข้อมูลขนาดใหญ่ระดับวิกฤต

ปลอดภัยตั้งแต่การออกแบบ

แยก Control Plane ออกจาก Data Plane และเข้ารหัสข้อมูลทั้งขณะจัดเก็บและขณะส่งผ่านเครือข่าย

จ่ายตามการใช้งานจริง

Pay-as-you-go ราคาโปร่งใสและเป็นมาตรฐานเดียวกันทั่วโลก ปรับขนาดทรัพยากรได้ตามความต้องการ

บริการอัตโนมัติ

Autonomous Database และ Autonomous Linux ปรับแต่งและอัปเดตแพตช์เองแบบไม่ต้องหยุดระบบ

OCI ยังทำงานร่วมกับคลาวด์รายอื่นได้ ผ่าน Oracle AI Database@AWS, @Azure และ @Google Cloud

บริการหลัก 11 กลุ่ม

IaaS ผู้ใช้ดูแลตั้งแต่ระบบปฏิบัติการขึ้นไป ส่วน PaaS ผู้ใช้ดูแลเฉพาะแอปและข้อมูล ผู้ให้บริการดูแลชั้นที่เหลือ

IaaS
Infrastructure as a Service

เช่าเครื่องเสมือน (Compute) เครือข่ายเสมือน และพื้นที่เก็บข้อมูลโดยไม่ต้องซื้อเซิร์ฟเวอร์เอง รวมถึง Block Volume

CaaS
Container as a Service

Container Engine for Kubernetes (OKE) ที่ Oracle ดูแลให้ พร้อม Container Instances และ Container Registry

PaaS
Platform as a Service

Integration Services, API Platform และ Analytics Services ให้นักพัฒนาโฟกัสที่แอป ไม่ต้องดูแลระบบปฏิบัติการหรือฮาร์ดแวร์

FaaS
Function as a Service

OCI Functions แพลตฟอร์ม serverless เขียนโค้ดเป็นฟังก์ชันเล็ก ๆ แล้วระบบรันเมื่อมีเหตุการณ์มาเรียกใช้

DaaS
Database as a Service

จุดแข็งที่สุดของ Oracle

Autonomous DatabaseBase DatabaseExadataPostgreSQLNoSQL
Security & Identity
ความปลอดภัยและอัตลักษณ์ผู้ใช้

โมเดลความรับผิดชอบร่วมกัน ใช้ IAM กำหนดสิทธิ์เข้าถึง แนะนำเปิด WAF บน Load Balancer เพื่อป้องกันเว็บแอป

IoT
Internet of Things

เชื่อมอุปกรณ์และเซนเซอร์เข้าเครือข่าย เช่น วัดอุณหภูมิห้องเซิร์ฟเวอร์แล้วแจ้งเตือนเมื่อเกินค่าที่กำหนด

STaaS
Storage as a Service

Object Storage, File Storage, Block Volume และ Archive Storage ที่ต้นทุนราวหนึ่งในสิบของ Object Storage

Big Data & Analytics
วิเคราะห์ข้อมูลขนาดใหญ่

Analytics Services, AI Data Platform, Autonomous Data Warehouse และ Integration Services สำหรับทำ ETL

BCaaS
Blockchain as a Service

Oracle Blockchain Platform ให้หลายองค์กรบันทึกธุรกรรมร่วมกันโดยไม่มีศูนย์กลางเดียว เช่น ห่วงโซ่อุปทานและการเงิน

LBaaS
Load Balancer as a Service

Load Balancer (Layer 4 และ 7) และ Network Load Balancer กระจายทราฟฟิกไปหลายเซิร์ฟเวอร์

ที่ตั้งศูนย์ข้อมูล

Oracle แบ่งพื้นที่ให้บริการเป็น Region และภายในมี Availability Domain กับ Fault Domain เพื่อให้ระบบทนต่อความขัดข้อง

Region

พื้นที่ทางภูมิศาสตร์ที่ตั้งโครงสร้างพื้นฐาน เลือกตามที่ตั้งผู้ใช้ กฎหมายข้อมูล และบริการที่ต้องการ

Availability Domain

ศูนย์ข้อมูลภายใน Region ที่แยกจากกัน จำนวนต่างกันในแต่ละ Region

Fault Domain

กลุ่มฮาร์ดแวร์ใน AD ใช้แยกทรัพยากร โดย 1 AD มี Fault Domain 3 กลุ่ม

ประเทศตัวอย่าง Regionเหมาะกับ
ไทยThailand Central (Bangkok)ผู้ใช้ในประเทศไทย หากบริการที่ต้องการรองรับ Region นี้
สิงคโปร์Singaporeระบบที่ให้บริการในเอเชียตะวันออกเฉียงใต้
ญี่ปุ่นJapan East (Tokyo)ผู้ใช้ในญี่ปุ่นและพื้นที่ใกล้เคียง
เกาหลีใต้South Korea Central (Seoul)ผู้ใช้ในเกาหลีใต้
ออสเตรเลียAustralia Eastผู้ใช้ในออสเตรเลีย

เลือก Region อย่างไร

  • ความเร็ว เลือกใกล้ผู้ใช้เพื่อลดความหน่วง
  • กฎหมาย ตรวจข้อกำหนดที่ตั้งและความเป็นส่วนตัว
  • ความพร้อมใช้งาน บริการที่ต้องการมีใน Region นั้นหรือไม่
  • สำรองและกู้คืน วางแผนข้าม Fault Domain หรือ Region
  • ค่าใช้จ่าย ราคาทรัพยากร การรับส่งข้อมูล และการสำรอง

ปัจจัยที่มีผลต่อค่าใช้จ่าย

Compute: OCPU หน่วยความจำ เวลาDatabase: ประเภทและขนาดStorage: ชนิดและปริมาณNetwork: การรับส่งข้อมูล

Free Tier

Free Trial เครดิตทดลอง 300 ดอลลาร์สหรัฐ นานสูงสุด 30 วัน ขึ้นกับประเทศและเงื่อนไขการสมัคร

Always Free ทรัพยากรบางรายการใช้ต่อเนื่องโดยไม่เสียค่าใช้จ่าย เช่น เครื่องเสมือน ฐานข้อมูล พื้นที่เก็บข้อมูล และเครือข่ายบางประเภท

ไม่ใช่ทุกบริการหรือทุกขนาดที่ใช้ฟรีได้

ตัวอย่าง: มหาวิทยาลัยสร้างเว็บไซต์ให้บริการข้อมูล

ประเมินจากทรัพยากรทั้งหมด ไม่ควรสรุปจากค่าเครื่องเสมือนเพียงรายการเดียว

  1. กำหนดจำนวนเครื่องและขนาดทรัพยากร
  2. เลือกประเภทฐานข้อมูลและพื้นที่จัดเก็บ
  3. ประเมินปริมาณการรับส่งข้อมูล
  4. ตรวจสิทธิ์ Free Tier ที่ตรงกับทรัพยากรนั้น
  5. คำนวณด้วยเครื่องมือ Oracle Cloud Cost Estimator

ข้อดีและข้อเสีย

ข้อดี

  • ฐานข้อมูลแข็งแกร่ง Autonomous Database และ Exadata หลายรูปแบบ
  • รองรับ multicloud ใช้ฐานข้อมูล Oracle ใน AWS, Azure, Google Cloud
  • มีของฟรีให้ทดลอง ทั้งเครดิตทดลองและ Always Free
  • จ่ายยืดหยุ่น Universal Credits ใช้ข้ามบริการและข้าม region
  • รองรับข้อกำหนดทางกฎหมาย มี region สำหรับรัฐบาลและ sovereign region
  • เรียนฟรี หลักสูตรและใบรับรองระดับ Foundations และ Architect Associate

ข้อเสีย

  • จำนวน region และบริการโดยรวมน้อยกว่า AWS, Azure, GCP
  • ชุมชนผู้ใช้ ตัวอย่างโค้ด และบุคลากรที่มีทักษะ OCI มีน้อยกว่า
  • Universal Credits มียอดผูกมัดรายปี ต้องประเมินการใช้งานล่วงหน้า และเครดิตที่เหลือสูญเสียไป
  • Always Free จำกัดเฉพาะ home region และไม่รองรับ US Government Cloud region

เส้นทางใบรับรอง (Certification Path)

Oracle University ปรับหลักสูตรปี 2026 เป็น 5 สายหลัก ได้แก่ OCI, Multicloud, AI, Agentic AI และ Database

ขั้นที่ 1 OCI Foundations Associate ฟรี

ระดับเริ่มต้น เนื้อหาเชิงแนวคิด ไม่ต้องมีประสบการณ์ลงมือทำ เหมาะกับนักศึกษา ผู้เปลี่ยนสายงาน และฝ่ายขายหรือไอที ข้อสอบรุ่น 2026 รหัส 1Z0-1085-26 แบ่งเป็น 4 หัวข้อ หัวข้อบริการหลักของ OCI สัดส่วน 50% รุ่นเดิมรหัส 1Z0-1085-25 ถูกยกเลิกเมื่อ 15 มิถุนายน 2026

ขั้นที่ 2 OCI Architect Associate ฟรี

เรียนรู้บริการหลัก เช่น Identity, Networking, Compute และ Storage ปัจจุบันเปิดให้เรียนและสอบฟรี ต่อยอดไปสาย Architect, Developer, Security, Networking และ Generative AI ได้

ขั้นที่ 3 Professional และสายเฉพาะทาง เสียเงิน

ตัวอย่างเช่น OCI Enterprise AI Professional (สร้างและดูแล AI agent ระดับองค์กร) และ Oracle AI Database@AWS/Azure/Google Cloud Architect Professional Oracle ระบุแผนเปิด Multicloud Foundations ในเดือนกันยายน 2026 และ Exadata Database Service ระดับ Professional ในเดือนตุลาคม 2026

สรุปผลการศึกษา

บริการและที่ตั้ง

OCI ครอบคลุมการประมวลผล การจัดเก็บข้อมูล การพัฒนาแอป ความปลอดภัย และการวิเคราะห์ข้อมูล มีศูนย์ข้อมูลหลายภูมิภาคให้เลือกตามความต้องการ

ค่าใช้จ่ายและข้อจำกัด

ค่าบริการยืดหยุ่นตามชนิดและปริมาณการใช้งาน ควรตรวจรายละเอียดก่อนใช้ ข้อจำกัดคือความรู้ทางเทคนิค การบริหารความปลอดภัย และการควบคุมค่าใช้จ่าย

ประโยชน์ต่อผู้เรียน

เส้นทางใบรับรองช่วยพัฒนาทักษะคลาวด์อย่างเป็นระบบ เป็นประโยชน์ต่อการศึกษาต่อและการทำงานในอนาคต
